## 唯一啟用策略

1. 15M：MA83採SMA；EMA200以最多499根資料、前200根SMA起算。收盤價＞SMA83＞EMA200只多；反向只空；其餘觀望。
2. 15M支撐壓力：左右各2根確認轉折。支撐為最低價至實體下緣，壓力為實體上緣至最高價。收盤越過遠端失效。多單需有有效支撐且價格在其上方，空單反向；不另強制觸區。
3. 5M：收盤首次突破當時已確認、尚未被收盤突破的前高／前低；突破量大於前20根均量。影線不算BOS；先破位但量不足，不追認同一轉折的後續補量。
4. BOS後12根5M內回測突破價並收回同方向才確認。確認K收盤價作限價參考，有效1根5M，之後新成交觸價才計進場，不回填歷史成交。趨勢轉向、參考區失效或超時則取消。
5. 停損：回抽觸及K至確認K極值外1tick。
6. Fib目標：BOS前最近已確認反向轉折為A（1）；BOS至回抽確認前推進極值為B（0）。不使用確認K內無法排序的新極值。TP1/2/3/FTP（TP4）＝0/−0.27/−0.618/−1。進場不再使用0.715。

價位確認後凍結。TP1含估算費用及滑價不足2R的候選仍顯示，但不建立部位。

## 風控與出場

初始200 USDT，單筆、全部持倉加待成交、同方向風險各最多5%；名目最多50x。卡片與交易使用同一份含費用、滑價、LOT與最小名目的部位預留，成交前再次核驗。

TP1出原始20%、TP2出30%、TP3出30%、TP4出剩餘20%，按step取整。每達TP，剩餘部位回撤該TP全出；首次觸價或重複同價不立即出清。

預設單邊費率0.05%、出場滑價0.02%。未計資金費率、強平及深度，跳價可超過風險預算。

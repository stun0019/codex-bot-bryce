# SMA83／EMA200 雙週期方向掃描

大框架 SMA83＞EMA200 列做多候選，SMA83＜EMA200 列做空候選，相等則觀望。MA83 使用收盤價簡單移動平均；EMA200 以最早200根均值起算後遞推，使用最多499根已收盤K線，不足200根不列候選。價格在兩條線上方、之間或下方均不改變方向。

兩組獨立掃描：4H定方向、15M顯示結構；1H定方向、5M顯示結構。同一商品可在兩組呈現不同方向，卡片清楚標示週期。週期與方向選單只影響顯示，不改變掃描範圍。小框架均線或MACD不作篩選。

卡片顯示小框架最新已確認高低點及轉折K時間。轉折高點嚴格高於左右各2根最高價；低點嚴格低於左右各2根最低價，右側2根收盤後確認。結構比較最近兩個已確認高、低點：HH＋HL抬高，LH＋LL降低，其餘含持平為不一致，不足兩組為資料不足。結構僅供主觀判斷，不過濾候選。

PERPETUAL與TRADIFI_PERPETUAL合併依24H USDT成交額取Top20，候選分加密與TradFi顯示。20個商品各掃兩組週期，最多40張候選卡；每5分鐘更新，行情訂閱及新聞商品去重。

# 4H趨勢＋15M回調結構：即時行情自動模擬

單一啟用策略：4H收盤價在EMA50之上，且EMA50高於3根前找多；反向找空。15M RSI(2)由前根低於10恢復至至少10，且收盤高於前根最高價，才確認做多；做空使用RSI由高於90回落至至多90且收盤跌破前根最低價。訊號僅使用已收盤資料，有效60秒，以之後新聚合成交報價模擬進場，不追補離線期間訊號。

停損：實際含滑價進場價外2倍15M ATR(14)。止盈：訊號當下最近已確認、位於進場方向且尚未被後續K線觸及的15M轉折高／低點，全部出場。轉折嚴格左右各2根確認，最多搜尋499根。沒有有效結構或目標不能涵蓋成本便略過。最長持有12小時，台北午夜按下一筆可核對成交平倉。

初始模擬帳戶100 USDT，50x保證金槓桿設定，數量按單筆含預估成本停損風險最多5%反推；全部與同方向總預估風險也最多5%，同時只持一單。50x不代表以全部本金開50倍部位。新策略起算100但不改寫既有持倉數量，舊持倉繼續追蹤；新版績效只計新版交易。已有不確定持倉或資金費率待核對時暫停新增。

即時來源為Binance公開USDT永續市場資料；PERPETUAL及TRADIFI_PERPETUAL合併24H成交額Top20，卡片分組。每5分鐘更新，符合完整進場條件才新增訊號。候選與模擬交易卡片共用風控數量及帳戶計算。單一15M結構止盈，不啟用1H＋5M、SMA83／EMA200、MACD或其他舊掃描策略。

## 手機使用

以HTTPS／GitHub Pages開啟site/index.html。需要支援Web Locks的瀏覽器，一個分頁負責成交追蹤，其他分頁唯讀。所有交易皆為模擬，只存目前手機／裝置、目前瀏覽器的localStorage；不需要API交易金鑰，也不發送真實訂單。不同裝置及不同瀏覽器不共用紀錄。

頁面在前景開啟時自動掃描／模擬下單。手機鎖屏、背景或斷線可能暫停，網頁不提供24小時常駐保證。返回後依聚合成交編號補查既有持倉、依時間順序判斷止盈／停損／時間平倉；不補開錯過的訊號。聚合成交無法完整取得時保留待核對，不虛構平倉。請定期匯出紀錄。

## 費用與紀錄

預設進出各0.05%費用、各0.02%不利滑價，可於介面調整後續訂單假設。以公開資金費率歷史及相應標記價格、持倉時間計算資金費；按時間去重，刷新不重複扣款。資金費率API錯誤時顯示待核對。預估5%是停損規劃上限，跳空及未來資金費不保證實際虧損封頂5%。未模擬市場深度或強平。

## 新聞

來源為Binance官方公告與GDELT DOC API，依本輪候選及持倉幣種比對，沒有相關新聞便不列卡片。GDELT時間是收錄時間，與原文發布時間區分。安全HTTPS連結、跨來源去重、短代號歧義過濾、來源獨立快取、429至少60秒退避及部分失敗提示。連線實測幣安公告可讀取；GDELT在目前測試IP回傳429，供應端限流時會標示來源不可用並繼續保留其他來源，不會假造新聞。利多／利空是標題規則初判，並非AI分析或交易條件。CryptoPanic、NewsData.io及CoinDesk另需API金鑰，目前未接入；不在公開GitHub Pages放金鑰。

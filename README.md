## 啟用策略

唯一啟用版本macd-lines-bos-4h15m-v1。每5分鐘掃描Binance USDT永續24H成交額Top20，只使用4H與15M最新已收盤K。

MACD(12,26,9)：EMA12／26分別以各期SMA起算，DIF訊號線以前9個DIF的SMA起算後遞推EMA9。最多499根，至少35根；與不同暖機長度或起算方法的平台可能略有差異。

- 4H DIF及訊號線均＞0：多頭；均＜0：空頭。
- 15M DIF及訊號線也必須在同方向零軸側才允許找進場。
- 任一線等於0、兩線異側或兩週期不同向：觀望。柱狀圖的正負不替代雙線零軸條件。
- 4H有方向先顯示等待15M回調候選，不因此建立部位。

15M轉折左右各2根收盤確認。放量收盤突破已確認且未破前高／前低，量大於前20根均量；12根內回測突破價並收回同方向才確認。影線不算BOS。確認收盤價作限價參考，計畫有效1根15M，之後新成交觸價才算成交，不補歷史進場。

不再採用EMA20/60/200排列、高框架觸區、RSI過濾或Fib0.715掛單等舊進場條件。

## 出場與風控

停損在回抽至確認K極值外1tick。BOS前已確認反向轉折為Fib1，突破後至確認K前推進極值為Fib0；TP1/2/3/4為0/−0.27/−0.618/−1。20%／30%／30%／剩餘20%分批，達TP後回撤該TP出清剩餘，首次觸價及重複同價不立即出清。

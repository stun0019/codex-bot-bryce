## 策略流程

每5分鐘更新目前24H成交額Top20，4H＋15M、1H＋5M各自獨立，僅使用已收盤K。高框架EMA20＜60＜200只空；鏡像排列只多，其餘觀望。EMA以最多499根收盤、SMA起算遞推，至少200根。

1. 高框架轉折左右各2根收盤確認。壓力區＝轉折高點K實體上緣至最高價；支撐區＝最低價至實體下緣。區域先成立，後續才允許觸區；高框架收盤越過遠端失效。
2. 空單進壓力區後，小框架收盤跌破當時已確認且未破壞的前低L0。影線刺穿不算。多單鏡像。
3. 取觸區後、突破時已由左右各2根確認的反向上漲K前高H，連到突破後、左右各2根確認的新低L1；多單反向下跌K前低至新高。
4. L1確認後預掛Fib 0.715，之後新成交觸價直接進場，不再加觸價後確認。0.5不進場。確認前已回抽0.715的波段略過，不補歷史成交。
5. Fib1外1tick停損，TP1/2/3/4為Fib0/−0.27/−0.618/−1。TP1含預估費用與滑價不足2R不預留。

觸區後等破結構、破結構後等新極值、計畫成立後等進場，各最多1根高框架時間。未成交前創新極值重新等L1；趨勢或區域失效取消。成交後錨點及目標凍結。

可選RSI＋放量：最近已收盤小框架Wilder RSI14（最多250根）多＜30、空＞70，成交量≥前根3倍（增加200%）。預設關閉，偏好存本機；沒有全合約隱藏掃描。

## 分批、風控與本機恢復

TP1出原始20%、TP2出30%、TP3出30%、TP4出剩餘（約20%，依step取整）。每達一個TP，剩餘部位回撤該TP即全出；同一觸價、重複同價不立即全出。後續有更有利報價再返回TP，或直接穿過TP，即觸發回撤出場。四段全出或回撤全出後才計平倉勝率，未達TP列先出場。

初始200 USDT；單筆、總持倉含待成交、同方向停損風險各最多5%，名目上限50x。卡片與模擬共用含手續費、停損滑價、LOT及最小名目限制的凍結預留數量，成交前再次核驗。5%為估算風險，跳價可超預算。達TP後依保護價與剩餘數量計風險及保證金。預設單邊費率0.05%、出場滑價0.02%，未計資金費率、強平及深度。

掃描所有候選同步模擬頁；未取得預留仍顯示未進場原因。卡片進場全列，下方停損/TP1、TP2/TP3、TP4/保護價各雙欄。刷新保留最近200筆候選，保留紀錄不重新開倉。沿用localStorage codex-paper-ledger-v1及codex-smc-card-records-v1，Web Locks單一分頁追蹤；舊EMA/SMC持倉與出場規則保留於舊策略，不改寫歷史損益。

已進場保存分批數量、保護價、費用及聚合成交ID。刷新或斷線後先核對連續aggTrades再恢復；無法證明才待核對。未成交計畫中斷保守取消，不回填進場。待報價右側保留新鮮成交現價。關閉網站不持續掃描，不同裝置不自動同步。

模擬與回測上方6項摘要固定每排兩格：帳戶累積盈虧、策略費後勝率、TP1～4觸及率。觸及率＝已觸及÷（已觸及＋先出場），排除未成交、追蹤中及待核對。

## 2026季度歷史回測

主頁補回歷史回測，Q1/Q2/Q3按台北時區切換，直接載入research/fib-2026-q1.json等預先計算報告，不需手動掃描。掃描歷史頁仍未啟用。

每季獨立200USDT，兩週期共用同一帳戶及5%總風險上限。累積盈虧以期末淨值計算，含未平倉損益；勝率只計費後已平倉交易。列兩週期歸屬績效、最大淨值回撤、目標觸及率、交易明細與行情覆蓋。

固定樣本為2026年11月取得的目前Top20，非當季歷史Top20，有存活者偏差；精度亦為取樣時規格。四週期資料先暖機（4H最多90天，其餘20天，實際指標最多499根）；訊號不混週期。5M OHLC只用於共同帳戶成交重播，逐根比較開高低收與開低高收，取當根較低淨清算價值；不能還原真實逐筆順序，歧義K另列。相同時點按固定成交額排名及4H優先預留，新釋放額度下一5分鐘才能分配。季末不虛構強制平倉。RSI額外過濾關閉。

這些是指定樣本與成本假設下的歷史估算，不代表未來持續獲利，也沒有為達指定報酬修改結果。舊research報告保留，但新版頁只載入當前Fib版本。

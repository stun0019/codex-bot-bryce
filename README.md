# MACD＋15M SMC 策略掃描

唯一現行策略：4H與15M MACD(12,26,9) DIF和訊號線全部＞0只多、全部＜0只空；其餘觀望。

15M收盤突破已確認前高／前低（左右各2根收盤確認，必須在突破K開盤前已知），以最近反向波段轉折到突破K之前的最後一根反向K，完整高低畫OB。突破後回踩OB，15M收盤朝趨勢方向離開OB，下一筆新聚合成交報價進場。觸區K自己可於收盤後確認，影線突破不算。OB不等於波段極值，兩者分開記錄。6小時未確認、MACD失去同向或OB停損被破即失效。

停損OB遠端外1tick，實際成交後重算單一2R目標，一次全部出場。手續費與滑價另扣，費後盈虧比低於2R；沒有分批或回撤TP出場。共用帳戶初始200USDT，單筆／總／同方向風險最多5%，同時只持一單，名目上限50x。部位與卡片共用成本與額度計算；跳價可能超出預估損失。

掃描PERPETUAL與TRADIFI_PERPETUAL合併的24H USDT成交額Top20；卡片分加密與TradFi區段。5M不產生進場訊號，只用於歷史成交路徑重播。

本版只保存SMC＋2R紀錄，使用新的瀏覽器ledger與candidate keys，舊策略不載入、不轉換、不列入績效。新版仍有Web Locks單一追蹤分頁與聚合成交檢查點，刷新／斷線後自動補查核對。沒有可保證的歷史銜接時保留待核對。

歷史回測8／9／10月使用同一signal與paper engine；月度獨立200USDT，靜態報告有版本檢查，按「更新回測」才重新計算並寫入當前版本IndexedDB。固定歷史樣本不是當時Top20，亦不代表即時TradFi掃描範圍；未計資金費率、強平及深度。績效不是獲利承諾。

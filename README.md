# 4H MACD＋15M BOS／OB／Fib

單一活躍策略：4H MACD(12,26,9) DIF與Signal都＞0只多，都＜0只空，不同側或零值觀望。MACD只計算4H；背離比對最近兩個已確認價格轉折與同根DIF，僅提醒、不參與篩選。

15M陽K收盤突破已確認前高（空頭鏡像）才成立BOS。前高／前低嚴格左右各2根已收盤K確認，影線穿越不算BOS。OB是BOS前最後一根反向K的完整高低範圍。突破後新波段端點也用左右各2根確認。做多Fib從OB低點拉到新高；做空從OB高點拉到新低，端點確認後固定，不使用未來波段重畫。

Fib0.715在OB內，掛該價；不在則掛OB近端：做多上緣、做空下緣。若確認端點之前，後續確認K已觸及掛單價便不補單。止損放掛單時已確認、BOS之前最近結構高低點之外1 tick。止盈Fib 0、−0.27、−0.618、−1，30%／20%／20%／30%分批，不添加移動停損或回撤全出。

限價單最多到BOS後6小時或台北午夜；4H方向改變、OB失效、進場前已到第一目標則取消。確認發生於觸價之後的歷史K不回填進場。持倉最長12小時、台北午夜依第一筆可核對成交平倉。

Binance公開即時行情＋瀏覽器自動模擬，沒有真實下單或交易金鑰。加密及TradFi合併24H成交額Top20，顯示分組，每5分鐘更新。候選卡可先顯示4H方向，15M未完成結構時不開單。手機前景才保證執行；背景／刷新會取消尚未成交掛單並補核對既有持倉，不保證24小時常駐。不同裝置／瀏覽器不共用localStorage，請定期匯出。

初始設定100 USDT、槓桿設定50x；數量按單筆、總帳戶與同方向預估停損風險最多5%計算，同時一單。策略替換不重設既有餘額，舊持倉保留原規則與核對能力，新績效僅計新版交易。

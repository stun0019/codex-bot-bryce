# Codex Bot Bryce — Binance EMA 策略掃描

靜態網站使用 Binance USDT 永續公開行情，不需要 API Key，不送出真實訂單。入口為根目錄 index.html 或 site/index.html；紀錄存在開啟網站的裝置／瀏覽器，沿用 GitHub Pages，沒有常駐後端。

## EMA20／60／200

新掃描完全改用EMA，不再以SMC、OB、FVG、CHoCH或MACD判定新訊號。每輪選目前24H USDT成交額Top20，獨立處理4H＋15M、1H＋5M，每5分鐘更新。

| 高框架排列 | 低框架方向 |
| --- | --- |
| EMA20＜EMA60＜EMA200 | 只空 |
| EMA20＞EMA60＞EMA200 | 只多 |
| 其他、均線相等或資料不足 | 觀望 |

只使用最新已收盤K。EMA以最前period根SMA起算，再按2/(period+1)遞推；每次固定最多499根，高框架至少200根、小框架至少21根。4H只配15M，1H只配5M。

低框架順高框架方向：當根高低範圍觸及EMA20後收盤回到趨勢側；或前根觸及並收在反向側、當根收回。多單收盤＞EMA20，空單＜EMA20，相等不算。若前根觸及加當根確認同時符合，停損計兩根極值。

進場參考為確認K收盤價，沿用限價模擬：候選確認後，等待新成交報價到參考價或更好價才模擬成交，保守記在參考價，不回填歷史收盤成交。停損為觸及／確認K的最低（多）或最高（空）外1tick。候選在下一根小框架收盤到期；進場前越過停損或TP1則取消。完成掃描後才新增，部分進度不開倉。

「更新」旁的RSI＋放量過濾保留為可選條件，預設關閉、偏好保存在本機。4H＋15M用已收盤15M，1H＋5M用5M，Wilder RSI14最近最多250根：多＜30、空＞70，且同根成交量≥前根3倍（增加200%）。前根零量、資料不足不通過。切換取消未成交並重掃，既有持倉依原計畫。沒有全合約背景RSI掃描。

## 掃描同步模擬交易

介面保留「策略掃描」「模擬交易」兩頁，歷史回測及掃描歷史頁面與其執行腳本已退出主頁，不再自動下載季度報告或保存新掃描回測快照。既有本機IndexedDB歷史資料及專案JSON檔保留。

每輪成功掃描的所有EMA候選都帶入模擬交易表格，按策略版本、週期及setup去重。風控通過者預留部位並等待觸價；其餘列「未進場」並顯示風控、暫停、到期等原因，不能當作持倉或平倉樣本。表格由實際交易帳本及最近200筆候選紀錄合併，不為了顯示而虛構交易或重建已成交訂單。

卡片維持進場全寬一列、停損／TP1、TP2／TP3各兩格一列；TP4與數量計算放入詳細資訊。顯示待進場、已進場、已平倉、已取消等實際狀態。刷新／空掃描保留最近200筆候選；保留紀錄不重新開倉。模擬「清空」會同時重設帳戶及候選紀錄，需使用者在頁面確認。

## 風控、出場及恢復

初始200 USDT，單筆、總持倉與待成交、同方向停損風險上限均5%，名目部位最多50x。多空風險不抵銷，待成交預留保證金及費用。部位依含進出費用與停損不利滑價的風險、可用保證金、LOT／最小名目限制計算。卡片與模擬共用凍結數量，成交前再次驗證，失敗顯示原因。風控不足時候選顯示於表格，只有獲得預留者會訂閱成交並嘗試進場。

TP1=2R出原始30%、TP2=3R出30%、TP3=4R出剩餘，按step取整；TP4=5R只觀察觸及率。原停損不移動。單邊費率預設0.05%、出場不利滑價0.02%；未模擬資金費率、強平與深度。5%是預估風險，跳價可超出預算。

沿用localStorage帳本codex-paper-ledger-v1與候選codex-smc-card-records-v1（沿用鍵名以保留資料），只有取得Web Locks的分頁追蹤。舊SMC／其他策略持倉保留原凍結出場及費用，歸於「舊策略」或「全部」，新EMA績效另計。

已進場持倉保存剩餘部位、分批成交、費用及聚合成交ID。刷新／斷線後先核對連續aggTrades再恢復，不用最新價格猜測離線觸價順序；無法證明則待核對。等待進場者若刷新／斷線則保守取消，不回填開倉。關閉網站沒有背景程式持續掃描，不同裝置不自動同步。

## 模擬交易上方資訊卡

模擬交易上方以固定兩欄顯示累積盈虧、策略勝率、TP1～TP4觸及率。累積盈虧取共用帳戶本期淨值報酬，含未實現損益；勝率與目標觸及率依所選週期，直接使用原有統計分母。帳戶風控、費用及詳細統計預設收合，策略頁仍保留原帳戶資訊。

# Codex Bot Bryce — Binance SMC 策略掃描

靜態網站使用 Binance USDT 永續公開行情，不需要 API Key，不會送出真實訂單。入口為儲存庫根目錄 index.html 或 site/index.html；可沿用 GitHub Pages。資料保存在開啟網站的那台裝置之瀏覽器，沒有常駐後端。

## 雙時間框架 SMC

原均線進場策略已取代。每輪依目前24H USDT成交額選Top20，獨立掃描兩套策略：

| 卡片標籤 | 區域週期 | 結構與進場週期 |
| --- | --- | --- |
| SMC · 4H＋15M | 4H | 15M |
| SMC · 1H＋5M | 1H | 5M |

只使用各自已收盤資料，不混用兩套週期。每5分鐘重掃；4H／1H／15M／5M各自快取到下一個收盤。請求間隔250ms、最多3個工作；限流依Retry-After停止，錯誤不偽造候選。

做空流程如下，做多為鏡像：

1. 高週期收盤跌破已確認的轉折低點，而且下跌實體至少為先前ATR14的1.2倍。從此前6根內取最後上漲K全高低範圍作供給OB。
2. 標示同向三根K的FVG；FVG重疊可供觀察，目前不是必要條件，也沒有舊評分邏輯。
3. 低週期先有HH／HL，再進入已事先確認的高週期供給區。轉折左右各2根，右側收盤確認後才能使用。已被破壞的結構不能重新當成首次CHoCH。
4. 低週期收盤首次跌破保護最後高點的HL，且有相同ATR位移門檻，確認結構轉空。回找此前6根內最後上漲K作進場OB。
5. 等待進場OB的50%中線回測。進場參考為中線，停損在進場OB及進區後轉折高點的較高者外加1tick。沒有回測不算成交，過去已回測的訊號不回填進場。
6. 觸區等結構、確認後等回測，各最多1根高週期時間。高週期收盤穿過OB遠端，或區域超過80根高週期K，取消未成交候選。已進場則依原凍結計畫追蹤。

策略卡片、模擬紀錄、掃描歷史及回測明細都標示所屬週期。可按週期篩選。舊紀錄保留原規則並標示「舊策略／未標示週期」，不改寫既有成交或績效。

## 資金與分批出場

新SMC預設參考資金200 USDT、單筆風險預算5%，初始10 USDT。前向模擬與回測把估算進出費用、停損滑價計入數量，再依LOT_SIZE向下取整。名目部位不等於保證金，也不強制用滿50x或75x。

| 目標 | 價格差R倍數 | 出場數量 |
| --- | --- | --- |
| TP1 | 2R | 原始部位30%，按step向下取整 |
| TP2 | 3R | 原始部位30%，按step向下取整 |
| TP3 | 4R | 剩餘全部，含取整餘額 |
| TP4 | 5R | 僅觀察觸及率，沒有剩餘部位可出場 |

原停損不移動，觸及後出清剩餘數量；已實現分批損益保留。數量不足以分三次出場則略過。新限價進場保守使用OB中線，不計進場滑價；出場使用觸發報價加不利滑價。預設單邊費率0.05%、不利出場滑價0.02%，可在模擬設定調整，並按每筆紀錄凍結。

只有全部出清才列入平倉勝率；淨損益大於0才算勝，停損出清也可能因先前分批獲利而淨獲利。觸及率分母只含已觸及與先停損，追蹤中／核對中／待核對不納入。TP4在TP3出清後仍觀察至觸及或原停損，不能改寫已平倉損益。舊三段紀錄沒有TP4，顯示未追蹤而非補造結果。

每筆訊號獨立模擬，沒有共用保證金或複利帳戶；累計損益不是200 USDT帳戶報酬率。5%是估算風險預算，跳價、費率變動等可能使實際損失超過預算。未模擬資金費率、強平與委託簿深度。

## 2026季度回測自動統計

site/research/index.json及六份完整JSON報告已預先計算2026 Q1、Q2、Q3，日期採台北時區，每季分開列4H＋15M與1H＋5M。回測頁自動顯示統計、預設載入Q3的4H＋15M，不需手動掃描。其他季度點「查看」即可載入既有報告，不重新跑行情。

資料採固定目前Top20與目前交易精度，並非歷史各時點Top20，存在選樣與生存者偏差。每季列平倉數、費後勝率、獨立訊號淨損益、平均淨R、行情／暖機覆蓋率；完整報告有警告、四段觸及率、交易明細與分組統計。未以累計獨立損益除以200冒充帳戶報酬。

歷史重播依當時已知K線確認OB與結構；限價須在計畫確認後才可成交。OHLC無法還原盤中先後：根內回測進場只計可能停損，不計同根止盈；已在開盤成交則可正常處理該根。既有持倉同根停損與目標雙觸價時預設停損優先，也可在進階回測選不確定並排除勝率。分批出場費用按各次實際模擬數量計算。

「進階：自訂歷史回測」保留兩套週期選擇、費率與固定名單／已保存排名；最多100天，另載20天暖機，資料量過大時要求縮短期間或減少合約。已保存排名只使用決策時間前15分鐘內完成的Top20快照，不推測缺失排名。舊報告可檢視，重新執行時會採新SMC；不再執行舊均線策略。圖表依交易切換4H／15M或1H／5M，標示OB／FVG、進出及目標，預先報告的圖表行情在點開時下載並快取。

## 刷新恢復與本機保存

沿用localStorage帳本codex-paper-ledger-v1及IndexedDB回測／掃描儲存。SMC去重ID包含策略版本、週期與setupId，同幣種同時間的兩套訊號可分開記錄。只有Web Locks取得鎖的分頁負責追蹤，其他分頁唯讀。

已進場持倉保存剩餘數量、每次分批成交、已實現費用、TP狀態與aggTrade編號。刷新／斷線後先核對中，再用連續聚合成交逐筆重播，驗證檢查點與先後順序後恢復或補記出場。已出場30%的腿不會因重播再次出場。資料缺漏或無法證明順序時保留待核對，排除相關統計；不拿最新價猜測過去結果。舊持倉照原凍結規則追蹤。

等待回測的限價候選若刷新、行情序列缺漏或超過30秒沒有新成交，保守略過，不補造離線期間的開倉。已進場持倉及未完成的目標觀察沿用既有自動補查。關閉網站沒有程式執行，重開才核對；不同裝置／瀏覽器／網站來源不會自動同步。

「清空」位於「暫停新增」右側，需使用者在頁面確認；清空本機模擬交易與檢查點，保留費率、暫停設定、回測與掃描歷史。清空時間會保存，舊訊號不會在同輪或刷新後重建；儲存失敗保留原帳本。可以JSON匯出，未在本次QA測試匯出下載。

## 保留隱藏 RSI＋爆量掃描

每次SMC掃描啟動，也背景獨立檢查所有交易中的USDT永續合約。連點頁首CODEX BOT五次，或使用site/index.html#rsi-volume開啟。隱藏入口不是權限控管。

條件為同一根最新已收盤15M的RSI(14)<30，且基礎資產成交量至少為前一根3倍，亦即增加200%；前根零量略過。RSI採Wilder平滑，最多250根收盤K，前14個變動平均起算。此名單獨立顯示，不是SMC的必要條件，也不建立模擬持倉。長掃描中的再次更新合併為後續一輪；取消／錯誤會標示不完整。
